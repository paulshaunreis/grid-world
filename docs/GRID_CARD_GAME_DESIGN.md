# Grid World — Card Game Design Direction

Status: DESIGN / concept-first
Date: 2026-10-06

## Creative target
The Grid World card game should feel ancient yet modern: collectible relics from a civilization whose history has been digitized, preserved, corrupted, rediscovered, and remixed.

Visual target: ancient manuscript / engraved artifact + advanced holographic interface + saturated neon history.

Do not clone Yu-Gi-Oh!, Magic, Pokémon, or D&D. Study successful design patterns and build an original Grid World rules language.

## Working game
Working title: Grid Relics.

Card types: Relic, Entity, Technique, Site, Protocol, Echo.

Working resource: Resonance. It is generated by the player's active Relic/Site network and can be banked, redirected, or disrupted. This is provisional and must be playtested.

## Board
1 Core/Relic slot; 5 Entity lanes; 3 Site/Protocol slots; discard/archive; reserve area; Resonance meter; visible history/replay log.

## Match rhythm
Draw → Synchronize → Deploy → Clash → Resolve → Archive.

The exact rules are provisional until a playable prototype is tested.

## Original hooks
Memory cards can reference historical events. World affinities allow regional identity without forcing mono-world decks. Discovery effects can unlock cosmetic lore/profile/archive records without making them raw power. Seasonal tournaments can permanently record champions and signature decks in the Grid archive.

## Packs and collecting
Products should include Starter Archive, Booster Pack, Archive Pack, Relic Vault, World Pack, Event Pack, Creator Pack, and Draft Kit.

Opening packs should be exciting through rarity, alternate art, foil/etched treatments, serialized historical editions, world frames, archive stamps, and useful cards. Older cards can gain value from real scarcity, provenance, beauty, and usefulness; no artificial profit guarantee.

Magic's current product model demonstrates that play-oriented packs and premium collector products can serve different purposes. citeturn1search0turn1search13

## Tournaments
Support casual, ranked, scheduled, seasonal, sealed, draft, guild/team, and world-region events. Server-authoritative prizes can include Grid Coin, cosmetic trophies, titles, visual effects, prestige, and card products.

## Land connection
Land can host card shops, tournament halls, collector galleries, deck-testing rooms, player markets, and championship venues. Venue prestige should grow from legitimate activity.

## Golden-ratio concept cards
For concept art, study a portrait composition based on the golden ratio rather than a generic trading-card layout. Approximate concept target: 1:1.618. Final production dimensions come later after digital and print testing.

## Animation
Pack opening: seal fracture → ancient glyph ring → digital light through engraved channels → cards rise → rarity reveal.

Card play: short readable summon/effect animations; rare cards can receive cinematic reveals; reduced-motion and mute options are mandatory.
