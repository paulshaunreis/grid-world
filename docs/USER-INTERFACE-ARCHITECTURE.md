# Grid World User Interface Architecture

Grid World should feel like one connected platform even when users move between web, 3D, creator, social, and live experiences.

## Primary navigation

1. **Home**
2. **Discover**
3. **Communities**
4. **Channels**
5. **Gallery**
6. **Events**
7. **Marketplace**
8. **Creator Hub**
9. **Profile**
10. **Enter World**

## Profile

A profile is a personal Grid space, not only an account page.

Recommended sections:

- Identity
- Status
- About
- Gallery
- Projects
- Creations
- Worlds
- Communities
- Channels
- Events
- Friends/followers
- Achievements
- Custom sections

## Creator Hub

Creator Hub is the home for creation tools:

- Quick Builder
- Advanced Builder
- Grid Script
- Asset Library
- Media Library
- Theme Studio
- Publish
- Version History

## Advanced Builder

Advanced Builder is the professional creation environment.

Modes:

- Object
- Edit
- Sculpt
- Terrain
- Paint
- Materials
- Lighting
- Animation
- World
- Logic
- Simulation

## Communities

Communities contain:

- Members
- Roles
- Text channels
- Voice channels
- Video rooms
- Forums/threads
- Announcements
- Shared media
- Events
- Moderation

## Channels

Creator channels contain:

- Live
- Chat
- Videos
- Clips
- VOD
- Schedule
- About
- Community
- Gallery

A channel may also be associated with a Grid World location.

## Gallery

Gallery is the artist/creator portfolio system.

It supports:

- Artwork
- Projects
- Collections
- Work in progress
- Images
- Video
- 3D assets
- Animation
- Credits
- Tags
- Comments
- Reactions
- Saves
- Sharing

## Grid Identity

The same theme can power:

- Web profile
- 3D HUD
- Chat
- Gallery
- Creator channel
- Communities
- Builder
- Notifications

Theme changes use:

`Edit → Preview → Publish → Realtime Sync`

Users can choose:

- Apply everywhere
- Apply to profile only
- Override by world
- Override by community/channel

## UI rule

Every major screen should answer:

1. Where am I?
2. What can I do here?
3. What belongs to me?
4. What belongs to the community?
5. How do I get back?

Grid World should favor consistent navigation and recognizable visual language over isolated mini-apps.
