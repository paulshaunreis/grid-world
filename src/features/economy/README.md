# Grid Economy

The Grid Economy feature owns user-facing economic concepts that are specific to Grid World.

## Responsibilities

- Grid Work
- marketplace earnings
- Grid Share
- creator compensation
- community funds
- economic activity summaries

## Does not own

- payment-provider credentials
- private keys
- authoritative financial balances
- banking credentials
- regulated custody
- unrestricted money movement

Those belong behind the Omni/server-side financial boundary.

## Initial principle

Users should be able to participate in Grid without paying for basic access, while having transparent opportunities to earn through useful contributions.

Any target such as $20/hour is an economic design objective, not a guaranteed wage or return.
